# Mr. Drew's Device & FPS Optimizer

Mr. Drew's Device & FPS Optimizer is a simple, fast desktop application designed to speed up your computer, free up system memory (RAM), stop game lag, and clean background junk.

It works on **Windows**, **Linux**, and **macOS**. It helps your games (like Fortnite, Valorant, Roblox, Minecraft, or Unreal Engine) run smoother with fewer stutters.

---

## Key Features

1. **Interactive Guided Tutorial**:
   - When you launch the app for the first time, a step-by-step tutorial pops up automatically.
   - It explains in simple words what every button does, why it helps, and when to click it.
   - You can skip it anytime or open it again later by clicking the **Interactive Tutorial** button at the top of the app.

2. **Super Fast C++ Performance Engine**:
   - Runs on a high-speed C++ engine so memory cleaning happens instantly without slowing down your PC.
   - Built to run safely across different operating systems without crashing.

3. **Clean & Easy Multi-Page Design**:
   - **Dashboard**: Shows your total RAM, free RAM, and CPU usage.
   - **FPS & Gaming**: Boost game speeds, fix lag, speed up game loading, and set high graphics power.
   - **RAM & Memory**: Clean up unused memory with one click.
   - **System Tools**: Clear temporary junk files, close unwanted background apps, and see which apps use the most memory.
   - **Tutorial & Guide**: Learn how to use all features with simple step-by-step explanations.
   - **Settings & Specs**: View your computer details or reset the tutorial.

## How to Run the App

### Windows (Easiest Way)
1. Open your Command Prompt or Terminal folder.
2. Run these commands:
   ```cmd
   git clone https://github.com/RaghavGogoi/Mr.-Drew-s-Device-Optimizer.git
   cd "Mr.-Drew-s-Device-Optimizer"
   run.bat
   ```
3. Double-clicking `run.bat` will automatically check requirements and start the application.

---

### Linux & macOS
1. Open your Terminal.
2. Run these commands:
   ```bash
   git clone https://github.com/RaghavGogoi/Mr.-Drew-s-Device-Optimizer.git
   cd "Mr.-Drew-s-Device-Optimizer"
   chmod +x run.sh
   ./run.sh
   ```

## Simple Guide to App Buttons

| Button Name | What It Does | Why Use It | When To Click It |
| :--- | :--- | :--- | :--- |
| **RUN FPS & GAME BOOSTER** | Optimizes your system timer, clears game caches, and sets high game priority | Stops game lag, fixes stutters, and lowers delay | Right before launching your game |
| **Fast Asset Loader** | Speeds up game disk read speeds | Prevents slow texture loading and popup delay | Before loading large game maps |
| **4GB Potato Mode** | Cleans memory using a light profile | Helps low-end computers (4GB RAM) run games smoothly | On budget or older laptops |
| **Ultimate Power** | Turns on maximum power mode for your processor | Prevents your CPU from slowing down during games | When gaming or editing video |
| **RUN MONSTER OPTIMIZER** | Performs a deep cleanup to reclaim free RAM | Frees up the maximum amount of unused memory (2-5 GB) | When your RAM usage is high |
| **Trim App RAM** | Compresses memory used by open apps like browsers | Reclaims memory without closing open apps | While multitasking with open apps |
| **Purge Standby RAM** | Clears cached memory held by the operating system | Fixes sudden out-of-memory crashes in games | When cached memory is taking up all your RAM |
| **Clear Temp Files** | Deletes safe temporary junk files | Frees up storage space on your hard drive / SSD | Once a week or when storage is low |
| **Boost Game Priority** | Tells your computer to focus its power on your game | Keeps your game running smoothly above background apps | After launching your game |
| **Clean Shader Cache** | Clears temporary graphics cache files | Fixes graphical glitches and shader stutters | After updating your graphics drivers |
| **End Bloatware** | Closes unnecessary background apps (OneDrive, Teams, etc.) | Saves memory and stops background CPU usage | On startup or before gaming |
| **Top RAM Apps** | Displays a list of apps taking up the most memory | Helps you see which apps are slowing down your PC | When diagnosing high memory usage |
| **Smart Auto-Guard** | Checks your memory every 60 seconds and cleans automatically | Automatic memory protection without needing to click | Turn on for long gaming sessions |

## Safe System Protection

The app includes a built-in **Safety Protection Whitelist**. Important Windows/Linux system files (like `explorer.exe`, `systemd`, `svchost.exe`) are protected so your computer will stay 100% stable and never crash.
